# Sponsoring JST

JST is maintained as open-source infrastructure. Sponsorship funds work that keeps generated applications safe and maintainable:

- React, React Router, Node, npm, and pnpm compatibility;
- architecture-rule maintenance and false-positive reduction;
- cross-platform CLI and migration tests;
- security response and provenance-backed releases;
- documentation, examples, AI-agent evaluations, and benchmarks.

Sponsor [@antonbelous0v on GitHub](https://github.com/sponsors/antonbelous0v) with a one-time or monthly contribution. Suggested levels are Supporter ($3–5), Backer ($15), Sustainer ($50), and Organization ($250+).

Sponsorship does not purchase technical decisions, hidden product features, priority over security or correctness, or a private support SLA. Sponsor recognition is opt-in and never inserted into generated applications or CLI output.

Project updates report releases, compatibility work, regressions, downloads, contributors, upcoming work, and material shared expenses. Until GitHub Sponsors onboarding is complete, the funding link may open the maintainer profile rather than a payment page.
