# Supported documentation versions

The documentation at this site describes the latest supported JST release. Immutable source documentation remains available with every release tag.

| Template | Documentation | Status |
| --- | --- | --- |
| `v0.4.18` | [Tagged documentation](https://github.com/jst-stack/jst/tree/v0.4.18/docs) | Current |
| `v0.4.17` | [Tagged documentation](https://github.com/jst-stack/jst/tree/v0.4.17/docs) | Historical |
| `v0.4.16` | [Tagged documentation](https://github.com/jst-stack/jst/tree/v0.4.16/docs) | Historical |

The machine-readable source of truth is [`jst.compatibility.json`](https://github.com/jst-stack/jst/blob/main/jst.compatibility.json). A version remains supported only while it appears in that manifest. Historical tags are retained for migration work but do not receive fixes after leaving the supported matrix.
