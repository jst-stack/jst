# Repository guidance

Before implementation or review work, read and follow [`skills/frontend-architecture/SKILL.md`](skills/frontend-architecture/SKILL.md). For ecosystem work, also read [`docs/ECOSYSTEM_ROADMAP.md`](docs/ECOSYSTEM_ROADMAP.md), treat it as the canonical decision/status contract, update it as work lands, and include its required current-state summary in every handoff. Inspect the nearest complete vertical slice before editing. Preserve the architecture kernel (`app/container`, feature injection, provider discovery, and architecture checks) when replacing the demo. Keep route modules thin and run `npm run check` before delivery.
