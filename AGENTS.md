# Repository guidance

Before implementation or review work, read and follow [`skills/frontend-architecture/SKILL.md`](skills/frontend-architecture/SKILL.md). Inspect the nearest complete vertical slice before editing. For a multi-feature request, decide and preserve ownership before writing files; a green layer-direction check does not excuse workflow logic placed in the wrong layer. Preserve the architecture kernel (`app/container`, feature injection, provider discovery, and architecture checks) when replacing the demo. Keep route modules thin and run `npm run check` before delivery. Optional code-index tools are accelerators: if one is unavailable or the new repository is not indexed, fall back immediately to repository-native discovery instead of blocking implementation.
